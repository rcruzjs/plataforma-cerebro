# Meu Book do NotebookLM

Coloque aqui os arquivos e notas que você exportou do seu NotebookLM. 

## Como exportar do NotebookLM:
1. **Notas e Guias**:
   - Vá para o seu notebook no [NotebookLM](https://notebooklm.google.com/).
   - No painel lateral ou no Studio, clique nos três pontinhos (`...`) da nota ou guia de estudo que deseja exportar.
   - Selecione **"Exportar para o Google Docs"** (Export to Docs) ou copie o texto diretamente.
   - Se exportou para o Google Docs, faça o download como **PDF**, **TXT** ou **Markdown** e coloque-o nesta pasta.

2. **Fontes (Documentos Originais)**:
   - Se as fontes forem arquivos do seu computador ou Google Drive, faça o download deles.
   - Coloque os arquivos (PDFs, TXT, etc.) aqui nesta pasta.

3. **Histórico de Chat**:
   - Copie as conversas importantes do chat e cole em um arquivo de texto (ex: `conversa_1.txt`) dentro desta pasta.

Depois de colocar seus arquivos aqui, podemos usar scripts ou ferramentas para analisar, resumir, buscar informações ou criar um aplicativo com base neles!
